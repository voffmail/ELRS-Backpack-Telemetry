Permissions
    Install-time permissions are granted automatically; notifications and battery exemption are requested on first launch.
    Quick setup guide
    ELRS backpack
    1. On the radio open ELRS Lua → Backpack → Telemetry → WiFi (not “WiFi Connectivity”).
    2. Connect the phone to the same network as the backpack: home Wi-Fi/hotspot or the “ExpressLRS TX Backpack” access point (password expresslrs).
    3. The backpack must send telemetry to the UDP port shown in Settings (14550 by default).
    App
    1. Allow notifications and battery exemption — otherwise Android may suspend reception in the background.
    2. Keep the app running; reception works in a foreground service even with the screen locked.
    3. Change the UDP port in Settings if needed; the listener restarts automatically.
    4. Choose a folder for tracks; existing tracks are copied to it.
    5. No data? Check the network, UDP port, firewall and that the backpack is in Telemetry WiFi mode.
