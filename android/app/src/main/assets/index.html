Quick setup guide
Project on GitHub
Two ways to receive telemetry
  • Wi-Fi — default. No extra hardware: the backpack starts an access point or joins your network.
  • ESP-NOW via USB — recommended. Less RF pollution. Needs an ESP32-C3/ESP32-S3 native-USB dongle and a data cable (no OTG adapter for USB-C↔USB-C).
Wi-Fi setup
  1. In EdgeTX open ELRS Lua → Backpack → Telemetry and select “WiFi”. Do not use “WiFi Connectivity” — it configures the transmitter.
  2. Connect the phone to the “ExpressLRS TX Backpack XXXXXX” access point (password expresslrs) or to the same network as the backpack.
  3. Start the app and open the “Telemetry” tab. UDP port 14550 is used by default.
  4. Wait for the green “online” status and growing packet counters in “Reception”. If the port was changed, set it in Settings (gear).
ESP-NOW via USB setup
  1. Flash the ESP32-C3/ESP32-S3 native-USB dongle with esp32-c3-usb-otg or esp32-s3-usb-otg via the Web Flasher or PlatformIO.
  2. In EdgeTX set: ELRS Lua → Backpack → Telemetry → ESP-NOW.
  3. Connect the dongle to the phone with a data cable (USB-C↔USB-C; use an OTG adapter only if needed) and allow USB access.
  4. Open Settings (gear icon in the header) and select the “ESP-NOW via USB” source.
  5. Set the binding phrase or manual UID matching the backpack.
  6. Check the dongle LED: with the correct bind phrase/UID it stays solid blue — the dongle is receiving frames from the backpack. With an active drone link it blinks. If the dongle is not connected to the app or the phrase/UID is wrong, the LED is off.
Possible problems
  • No Wi-Fi data? Check Telemetry → WiFi, the shared network, VPN, and that UDP port 14550 is not used by another app.
  • No dongle in USB mode? Use an ESP32-C3/ESP32-S3 native-USB board and a data cable; check USB permission.
  • Counters grow but the status says “no drone link”? Check RX/drone power and that the binding phrase or UID matches.
  • Port 14550 busy? Change it in Settings (gear → UDP port).
  • Some vendors' “ExpressLRS TX Backpack XXXXXX” AP does not start; a backpack firmware from master may help.
Backpack flashing
  • Flashing is needed if the backpack does not start Wi-Fi/ESP-NOW or the menu item is missing. Flash via ExpressLRS Configurator → Backpack.
  • Binding phrase is optional for Wi-Fi telemetry: the app does not check the UID.
  • For ESP-NOW the phrase produces the UID and ESP-NOW group address; use the same phrase as your ELRS link or set a manual UID in the dongle settings.
  • Without a phrase the backpack uses the EEPROM group address (after binding) or leaves it zero; Wi-Fi telemetry still works. The AP password is always expresslrs.
  • Changing the phrase changes the UID and SSID — reflash all devices in the group with the same phrase.
Tx Backpack Setup — ExpressLRS
App
  1. Allow notifications and battery exemption — otherwise Android may suspend reception in the background.
  2. Keep the app running; reception works in a foreground service even with the screen locked.
  3. Source and options are in Settings (gear icon). Wi-Fi is the default; ESP-NOW via USB is recommended.
  4. Choose a folder for tracks; existing tracks are copied to it.
  5. The app keeps receiving in the background: the Back button only hides the window.
  6. To stop reception and close the app, press “Close app” at the bottom of the Telemetry tab (or “Stop” in the notification).
